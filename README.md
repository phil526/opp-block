# OPP BLOCK — Episode 1: "Who Nicked the Broadcast?"

A grounded, satirical third-person shooter set at night in Brixton, London. Runs in the browser (Three.js, WebGL 2).

**Play:** https://phil526.github.io/opp-block/

Desktop browser with a mouse recommended. Contains strong language and violence. Satire; all characters, crews and businesses are fictional. Character models and animations are CC0 (see `assets/CREDITS.txt`).
